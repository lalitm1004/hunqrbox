# hunqrbox
A WebApp-PWA with the sole purpose of displaying QR codes of a 6 digit numeric sequence. Truly the pinnacle of my work

# Running Locally
1. Clone repo
```bash
git clone https://github.com/lalitm1004/hunqrbox.git
cd hunqrbox
```

2. Install requirements
```bash
npm i
```

3. Run dev server
```bash
npm run dev
```
